# ADR 0001 – Spec als Wahrheit, Abweichungen per ADR

Status: angenommen

`PROJECT.md` ist die verbindliche Spezifikation (Arbeitsregel 26.1). Jede bewusste Abweichung
wird hier als ADR mit Begründung festgehalten; die Spec wird im selben Änderungssatz angepasst,
falls die Abweichung dauerhaft ist. Offene Fragen werden als ADR-Vorschlag (Status „vorgeschlagen“)
gestellt, nicht im Code geraten.
