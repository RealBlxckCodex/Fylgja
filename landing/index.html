01 · persistence

Not a chat tab. A colleague who stays.

Every agent has long-term memory, an event-sourced journal and a heartbeat. It picks up where it left off — even days later — and speaks first when something matters.

Mon 09:12

You tell it once

“Our client prefers invoices on the 1st.” Stored in memory, with provenance.

Tue 03:00

It keeps working

Scheduled routines run while you sleep, on your own GPUs or laptop.

Thu 08:30

It reaches out

Pulse notices the invoice is due and pings you on Telegram, Discord or the web UI.

Fri

It learns

Your 👍/👎 and corrections become reviewed skills — never silent self-modification.

Memory that’s inspectable

PostgreSQL + pgvector. Browse, edit and delete what your agent knows. Nothing hidden.

Proactive by design

Pulse schedules, triggers and quiet hours. Autonomy levels L0–L3 decide how far it may go alone.

A real computer

Browser and desktop in an isolated sandbox. Watch live over noVNC — and grab the mouse any time.

02 · security

The prompt is not a security boundary. The executor is.

Fylgja assumes the model will be tricked. So policy, approvals and taint tracking run outside the model, in the tool executor. Deny by default.
